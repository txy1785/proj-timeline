# 体验改善实施与验收

日期：2026-10-27。用户已授权按 [改善方案](../体验改善设计方案-v1.md) 实施。此页记录运行界面与验证结果，静态设计图仍保留在 [原型图册](../../prototype/ux-v1/README.md)。

## 已实施的使用路径

| 使用场景 | 改善后的行为 |
|---|---|
| 成员开始工作 | USER 登录默认进入“我的工作”，按本人、可读项目与业务日期读取任务；点击名称打开统一任务详情，状态与文字记录分开保存 |
| 负责人查看项目 | 概览先显示交付目的、负责人、完整计划日期、风险原因、下一阶段目标及本周计划；风险可直接进入具体工作项 |
| 建立交付工作 | 统一“新建工作项”显式选择功能模块或项目级位置，继承相应负责人；任务简表先填名称/执行人/可选截止日，补充字段折叠且保留原值 |
| 完成交付 | 任务状态带 expectedStatus；冲突读取最新状态并保留记录草稿。工作项须先完成任务，由负责人确认完成；交付物清单不阻断完成 |
| 查看排期 | 每项独立行，固定名称/负责人/进度；共用日期轴、项目目标行、业务今天线、周/月及范围选择，保留交付物数量 |
| 提交缺陷 | 先读取真实接收位置；提交时重新检查；失败保留输入，成功显示实际接收位置及任务深链 |
| 设置与审批 | 基本信息、成员、阶段目标、模块申请分签；模块负责人直接编辑本模块；审批展示当前与申请内容，通知可直达具体申请 |
| 发布及查看周报 | 支持周深链与历史快照；先保存当前说明再发布；保存/发布期间阻止切周，已发布内容保持只读 |
| 通知、文件和人员负载 | 中文通知、真实未读与分页；任务文件可回到正确工作项；负载数字与明细同范围，本周计划人天包含已完成任务 |

## 真实 MySQL 与浏览器验收

使用明确命名的本机隔离测试库 `pt_ux_verify_20261027_a91f`，由原 Flyway V1—V12 创建结构。公开演示种子导入前严格替换并检查 USE 目标，再使用真实 HTTP 创建验证项目；未向用户库导入演示或测试数据。

- 验证模块负责人直接编辑，普通执行人及 VIEWER 越权被拒绝；非成员不能读取指定项目，聚合列表也不泄露其数据。
- 验证本人任务/已完成/历史范围与计数、409 状态冲突、独立记录、未完成任务阻断工作项完成、缺陷接收预判无写入、关闭原项后分流至进行中的项目级 BUGFIX。

- 验证 WORKLOAD_PLAN 包含 DONE、明细人天之和等于汇总；任务级附件返回正确 nodeId，VIEWER 删除返回 403。
- 使用无头 Chromium 连接真实前后端，验证实际登录默认页、本人任务、任务深链和项目导航、概览/排期、创建表单的空位置与负责人提示、已发布周报、阶段目标设置及 VIEWER 只读。未出现浏览器运行异常。

独立审核发现并复核修复 5 项：计划人天明细遗漏已完成任务；权限变化隐藏草稿；关闭项受阻历史计入当前风险；周报保存中切周响应串写；末页任务完成后的假空列表。相关 SQL 与浏览器回归已加入仓库。
